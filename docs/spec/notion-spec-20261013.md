## 抓取细节备忘（skill 固化用）

1. HTTP 直抓 / WebFetch 拿到空壳（SPA），必须走浏览器渲染通道（本机 Playwright MCP 实测可用；集成浏览器 client 工具 readPage 会超时卡死，勿用）。
2. 分组默认折叠，行不渲染。需逐个点击组标题展开（叶子元素文本精确匹配组名）。
3. 行容器特征：8–12 个子格 DIV，cells[0]/cells[1] 为空（勾选框+空位），cells[2]=名称、[3]=类型、[4]=ID、[5]=状态、[6]=优先级、[7]=阶段、[8]=DDL、[9+]=备注。
4. 虚拟滚动陷阱：触底时行未必渲染完，需触底后再等 ~700ms 补收 2 次；组标题被虚拟化移出 DOM 时，其行会错归给上一组——小步长（350px）多趟采集可让标题与行同帧出现。
5. 聚合容器噪声：某层父容器把整组行文本并成一个子格，用「cells[1] 必须为空」过滤。
6. `main.innerText` 在单次快照里能拿全当前 DOM 渲染的内容，可用于校验行数。
