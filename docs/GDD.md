# 01｜游戏身份

**暂定名：《魔法回路》**

**类型：** 2D / 2.5D 即时平台 + 环境魔法 + 系统涌现

**玩家幻想：** 扮演改变环境，利用环境的魔法师。在环境间跳跃，前往深渊。

# 02｜三个设计支柱

## ① 环境即时反馈

- 详细说明

    玩家只做一个简单动作：**投出一颗魔力种子。**

    种子落下后，环境必须立刻回应。

    种子：与连接周围、产生魔法。

    环境：根据魔法效果产生变化

## ② 小因，大果，连锁反应

- 详细说明

    玩家只能通过投掷种子产生的魔法，

    间接影响场景：消失、塌陷、重力等

    不能直接制造：桥 / 通道 / 阶梯

    环境的变化，会使得变化后的方块进一步产生新的回路，使得一个种子能造成连锁反应。让玩家能理解并熟练利用。

## ③ 多解法

- 详细说明

    关卡设计师只提供：**初始局面 + 底层规则 + 目标。**

    避免设计固定关卡解法

# 03｜游戏核心目标

**玩家目标：不断向下，到达区域终点。**

**玩家困境：当前无法通过的空间状态、有限的魔力种子、关卡倒计时。**

**游戏失败：倒计时归零**

# 详细介绍：类型 故事 机制

> 玩家在不断向下探索遗迹，利用改变环境的魔力种子为自己开辟道路。玩家投掷的「魔力种子」，会根据规律与周围方块连成回路，产生魔法，以「重力」「消失」「塌陷」等方式改变环境。玩家将观察环境，管理时间与剩余种子的使用，尽可能利用魔法形成的新局面，为自己创造向下的通路。最终到达终点

# 特色功能

- 玩家角色平台跳跃
- 投掷魔力种子改变环境
- 消耗剩余时间挖掘魔力种子

# 界面

- 输入：左手键盘 + 右手鼠标
- ui：2d 平面
- 游戏场景：3d 空间，2d 多层画面
